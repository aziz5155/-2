# أثر — مواد التقديم لمسابقة SAIF

مواد تعريفية بمشروع «أثر — مساعد ذكي للبحث عن المفقودين»، جاهزة للاستخدام والتعديل.
المشروع في **مرحلة التصميم**؛ كل الواجهات والخرائط والمحاكاة والبيانات الظاهرة في هذه الملفات **تجريبية بالكامل** ولا تمثل نتائج فعلية.

## ١. صورة المشروع — `01-project-image/`

- **project-image.png** — صورة تعريفية جاهزة، 3840×2160px (تعادل 1920×1080 بدقة ×2)، تعرض واجهتي المسافر والمتابعة وخريطة توضيحية.
- **project-image.html** — المصدر القابل للتعديل (نص، ألوان، بيانات) مباشرة بأي محرر نصوص أو متصفح.
  - لإعادة التصدير إلى PNG بعد التعديل: `node scripts/render.py 01-project-image/project-image.html 01-project-image/project-image.png 1920 1080 2` (من مجلد المشروع، عبر Python).

## ٢. الملصق العلمي — `02-poster/`

- **athar-poster.pdf** — نسخة جاهزة للرفع والطباعة، مقاس 594×920mm (بورتريه).
- **athar-poster.pptx** — نسخة قابلة للتعديل الكامل في PowerPoint (نصوص وأشكال حقيقية، وليست صورة).
- **poster.html** — مصدر نسخة PDF، قابل للتعديل مباشرة.

القالب الرسمي للمسابقة لم يُرفق؛ المحتوى منظَّم بعناوين وأقسام واضحة (المشكلة، الهدف، طريقة العمل، القيمة، تصور الواجهات، خطة التحقق، المصادر) بحيث يسهل نقله لاحقًا إلى أي قالب رسمي يصل من الجهة المنظِّمة.

**المصادر المعتمدة في الملصق:**
- Koester, R. — *Lost Person Behavior* — dbs-sar.com/LostPersonBehavior.htm
- dbS Productions — قاعدة بيانات ISRID الدولية — dbs-sar.com/SAR_Research/ISRID.htm
- IMO/ICAO — دليل IAMSAR — imo.org/en/ourwork/safety/pages/iamsarmanual.aspx
- SARBayes — نماذج بايزية لاحتمالية مناطق البحث — sarbayes.org
- National Park Service — دليل خطة الرحلة (Trip Plan) — nps.gov/articles/gtgtripplan.htm
- الهيئة العامة للهلال الأحمر السعودي — srca.org.sa

## ٣. العرض المرئي (للفيديو التعريفي) — `03-video/`

- **athar-presentation.pptx** — عرض من ٧ شرائح، مقاس عريض 16:9، جاهز لعرضه وتسجيل شرحك الصوتي فوقه.
  نص الإلقاء الكامل موجود في **ملاحظات كل شريحة (Speaker Notes)**.
- **narration-script.docx** — نفس نص الإلقاء مرتّبًا في جدول حسب المشاهد مع الزمن المقترح لكل مشهد، بالإضافة إلى **طريقة تسجيل الشرح بصوتك من الآيفون** خطوة بخطوة.

**ترتيب الشرائح:** المشكلة ← فكرة الحل ← تسجيل الرحلة ← التنبيه عند التأخر ← بطاقة المعلومات ← محاكاة مناطق البحث وتحديثها ← القيمة المتوقعة وخطة الاختبار.
المدة الإجمالية المقترحة للسرد نحو ٣ دقائق (الحد الأقصى المطلوب للفيديو النهائي: ٥ دقائق و١٥٠ ميجابايت).

**ملاحظة على ما لم يُنفَّذ:** لم يتم إنتاج فيديو صامت جاهز من الشرائح تلقائيًا (بيئة التنفيذ الحالية لا تملك أداة تحويل عرض PowerPoint إلى صور/فيديو). البديل العملي الموصوف في `narration-script.docx` — تسجيل شاشة الآيفون مباشرة أثناء تشغيل العرض والتحدث فوقه — يُنتج الفيديو النهائي مباشرة بخطوة واحدة، وهو المسار الموصى به.

## الهوية البصرية الموحّدة

جميع الملفات الثلاثة تستخدم نفس الاسم والشعار والألوان (كحلي `#0B1F3A`، أخضر بترولي `#12746F`/`#22A79A`، لون تنبيه محدود `#E8613C`) ونفس البيانات التجريبية (الوجهة، المواعيد، الأسماء) لضمان الاتساق.

## إعادة توليد الملفات (اختياري)

الملفات مبنية بأكواد داخل `scripts/` (تُشغَّل بـ Node.js وتحتاج `npm install` مرة واحدة من هذا المجلد):

```
npm install
node scripts/build_poster.js       # يعيد بناء 02-poster/athar-poster.pptx
node scripts/build_deck.js         # يعيد بناء 03-video/athar-presentation.pptx
node scripts/build_narration_doc.js # يعيد بناء 03-video/narration-script.docx
```

لتوليد ملف athar-poster.pdf من poster.html بعد أي تعديل، استخدم أي متصفح حديث (فتح الملف ← طباعة ← حفظ كـ PDF)، أو Chrome من سطر الأوامر: `chrome --headless --print-to-pdf=out.pdf poster.html`.
