# مواد معرض الأعمال — مستقل

| المجلد | المشروع |
|---|---|
| `01-nabd-project-management/` | نبض — نظام إدارة المشاريع والمهام |
| `02-mawidak-booking-platform/` | موعدك — منصة حجز وإدارة المواعيد |

كل مجلد يحتوي على:
- `thumbnail-1280x720.png`: الصورة المصغرة
- `screens/`: أربع صور للواجهات بمقاس 1920×1080
- `presentation.pdf`: ملف العرض (11 صفحة)
- `نصوص-العرض.txt`: العنوان والوصف وقائمة المهارات جاهزة للنسخ

## إعادة التوليد
المصادر في `_src/` (HTML وCSS وبيانات تجريبية). لإعادة توليد جميع الصور وملفات PDF:

```bash
cd portfolio/_src && ./make.sh
```
يتطلب Node.js مع Playwright وPython 3 مع Pillow.
