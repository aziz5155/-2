# الملفات المصدرية — نماذج الشعارات الثلاثة (رواسخ، مدارج، مرقاب)

نماذج تصميمية مفاهيمية أُعدّت لأغراض استعراض المهارات، ولا تمثل شركات أو جهات قائمة.
الأسماء مفاهيمية مؤقتة، وغير مخصصة للاستخدام التجاري قبل التحقق من توفرها.

## المحتويات

| المجلد | المحتوى |
|---|---|
| `logos/01-rawasikh` `logos/02-madarij` `logos/03-mirqab` | ملفات SVG المتجهية لكل شعار: أفقي، رأسي، رمز، كلمة شعارية × (ملوّن، معكوس، أحادي). النصوص فيها محوّلة إلى مسارات، فلا تحتاج خطوطًا لتُفتح. |
| `code/symbols.py` | رسم الرموز الثلاثة هندسيًا على شبكة 100×100 — أهم ملف لتعديل الرموز. |
| `code/brands.py` | بيانات كل هوية: الاسم، الألوان (HEX)، الخطوط، نصوص الفكرة. |
| `code/logos.py` + `code/shape.py` | تركيب الشعارات: تحويل الاسم العربي إلى مسارات (HarfBuzz) واستبدال نقطة الحرف بعنصر الرمز. |
| `code/patterns.py` | الأنماط البصرية المشتقة من كل رمز. |
| `code/slides.py` | صفحات دليل الهوية والتطبيقات (بطاقة، ورق مراسلات، ملف تعريفي، لوحة، موقع). |
| `code/concepts.py` | ملف «نماذج شعارات مفاهيمية» المختصر (يتضمن أيضًا شيفرة نسخة المعاينة). |
| `code/make.py` `code/texts.py` | بناء كل المخرجات (SVG، PNG، PDF، الصور). |
| `code/export.js` `code/svg2png.js` | التصدير إلى PDF وPNG عبر Playwright. |
| `code/*.html` | صفحات HTML المولّدة (الأدلة، المعرض المجمّع، النماذج المختصرة) قبل تصديرها. |
| `code/ttf` `code/fonts` `code/fonts.css` | الخطوط المستخدمة. |
| `licenses/` | تراخيص الخطوط (SIL Open Font License 1.1). |

## إعادة البناء

المتطلبات: Python 3 مع `uharfbuzz` و`Pillow` و`pypdf`، وNode.js مع `playwright` (ومتصفح Chromium).

```bash
pip install uharfbuzz pillow pypdf
npm install playwright && npx playwright install chromium
cd code
python3 make.py        # الشعارات + أدلة الهوية + الصور + المعرض المجمّع
python3 texts.py       # ملفات الشرح النصية
python3 concepts.py    # ملف النماذج المختصر
```

تُكتب المخرجات في مجلدات بجانب `code/` (مثل `01-rawasikh/`).

## الخطوط وتراخيصها

Noto Kufi Arabic، Almarai، Alexandria، IBM Plex Sans Arabic، Readex Pro — جميعها مرخّصة بـ SIL Open Font License 1.1 (النصوص الكاملة في `licenses/`)، وتسمح بالاستخدام في التصاميم وتضمينها في الملفات.
لم تُستخدم أي صور أو أيقونات أو قوالب من مصادر خارجية؛ الرموز والأنماط وملمس الورق مولّدة بالشيفرة.
